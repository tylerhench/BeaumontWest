How to use the logo. Hand this to anyone building the website, printing something, or setting up a profile.

The four marks

Primary

Default everywhere. Use on light backgrounds at 64px and above.

Simplified

Letters removed. Use below 64px — favicons, app icons, small avatars.

Reversed

For dark backgrounds where the cream disc would look heavy.

One ink

Single-colour reproduction: embroidery, stamps, etched signage, fax.

Colour

Deep teal #1B4552

Structure. Mountain, ring, body text, headings.

Cream #FDF0DC

Backgrounds and knockouts. The disc and the letters.

Coral #E86F51

The sun. One accent, used sparingly.

Peach #F4A261

The W only. Reserved — don't spread it around.

Contrast, measured against WCAG AA. The accents are weaker than they look — check this table before using either one for text.

Teal on cream9.25:1Body text, headings, anything
Cream on teal9.25:1Body text, headings, anything
Peach on teal5.04:1Body text — the only accent pairing that passes
Coral on teal3.38:1Large text over 24px only
Coral on cream2.74:1Decorative shapes only, never text
Peach on cream1.83:1Decorative shapes only, never text

Clear space

Keep a margin of at least a quarter of the badge's width on all sides. Nothing — type, images, page edges, other logos — comes inside the dashed line.

Minimum size

Shown at true size. Below 64px the B and S stop being readable, which is what the simplified mark is for.

Don't

  • Recolour it. The four colours are the identity; a teal-and-purple version is a different logo.
  • Stretch or squash it. Scale proportionally, always.
  • Add shadows, glows, bevels, or outlines.
  • Rotate it, or tilt the badge off horizontal.
  • Use peach or coral for text on cream. They fail contrast — see the table above.
  • Place the reversed mark on a busy photograph. Use the full mark, whose cream disc gives it a field.
  • Retype the B and S. They're outlined vectors; rebuilding them in a font won't match.
  • Use the full mark below 64px. Switch to the simplified one.
